# Python OOPs Project

## Overview
This project demonstrates Object-Oriented Programming (OOP) concepts in Python through a simple banking system.

## Features
- Account creation
- Deposit money
- Withdraw money
- Display account balance
- Calculate interest

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Sample Output
```text

Deposit successful
Withdrawal successful
Balance: 500
Withdrawal successful. Balance: -10
Interest: 20.0
```

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python "Python OOPS Project.py"
```

## Learning Outcomes
Practiced Python classes, objects, methods, and basic banking operations
